# Αποφάσεις της ομάδας

Εδώ γράφεται κάθε απόφαση που αφορά όλη την ομάδα, ιδίως όταν κάνουμε κάτι **διαφορετικά** από τη βάση
(reference-app). Ο Νίκος την καταγράφει μετά τη συνάντηση· οποιοσδήποτε μπορεί να προτείνει νέα γραμμή με PR.

Η στήλη «Βάση» λέει τι κάνει η εφαρμογή αναφοράς (λεπτομέρειες στο `reference-app/SXEDIASH.md`, ενότητα ε).
Η στήλη «Απόφαση» συμπληρώνεται από εμάς.
