# 1.5 Προδιαγραφές περιπτώσεων χρήσης

Ομάδα 12 · Υπεύθυνος: Απόστολος Δαγκλής (Αναλυτής & Ελεγκτής)

Μία προδιαγραφή ανά UC του [1.3](../1.3-apaitiseis.md). Κάθε αρχείο έχει: πίνακα στοιχείων (λειτουργίες, NFR, actors,
οθόνη UI-xx, σχέσεις include/extend), σύντομη περιγραφή, προϋποθέσεις, βασική ροή, εναλλακτικές ροές και μετασυνθήκες.

**Αρίθμηση εναλλακτικών ροών.** `5a1` = η 1η εναλλακτική στο βήμα 5 της βασικής ροής. Όπου ένα βήμα έχει
εντελώς διαφορετική πορεία (π.χ. «Ξεκλείδωμα» αντί για «Κλείδωμα» PDF) γράφεται χωρίς τελικό αριθμό (`2b`).
Κάθε εναλλακτική ροή σφάλματος γίνεται ένα αρνητικό test (2.4).

Οι οθόνες είναι αυτές του [`othones-UI.md`](../othones-UI.md). Το διάγραμμα και η αιτιολόγηση των σχέσεων είναι στο
[1.4](../1.4-uc-diagram/).
