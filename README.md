# Ομάδα 12 — Εργαλείο Ασφάλειας Προσωπικών Δεδομένων

Ομαδική εργασία στο μάθημα **Μηχανική Λογισμικού** (ΔΙΠΑΕ, 2026-27).

Desktop εφαρμογή σε Java για κρυπτογράφηση κειμένου, αρχείων και PDF, προστατευμένο χώρο αρχείων (Secure Vault),
ψηφιακές υπογραφές, στεγανογραφία και ένα εργαστήριο κρυπτογραφίας. Όλη η επεξεργασία γίνεται τοπικά, χωρίς
σύνδεση στο διαδίκτυο και χωρίς βάση δεδομένων.

## Πώς τρέχει

> _Συμπληρώνεται όταν ανέβει η πρώτη εκδοχή που τρέχει (Ε5)._

Απαιτήσεις: JDK 17 ή νεότερο, Maven 3.8+ (ή IntelliJ IDEA).

```bash
cd app
mvn clean test
mvn javafx:run
```
